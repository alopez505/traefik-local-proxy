# Certificates

This directory is for local, generated TLS assets used by Traefik during development.

Certificates are generated by mkcert. The CA private key is **not** kept here;
mkcert stores it in its own CAROOT (`mkcert -CAROOT`), outside this repo.

Tracked in Git:

- `README.md`

Generated locally and gitignored:

- `ca.crt` (a copy of the mkcert root CA, for importing into the Windows trust store)
- `localtest.me.crt`
- `localtest.me.key`
- any other generated certs or private keys

To generate or regenerate the wildcard certificate:

```bash
./scripts/generate-dev-certs.sh          # generate if missing
./scripts/generate-dev-certs.sh --force  # regenerate the leaf (reuses the mkcert CA)
```

Because `--force` normally reuses the existing mkcert CA, a CA already imported
into Windows stays trusted; you do not need to re-import after regenerating the
leaf. If mkcert's CA was changed or reset, import the new CA again.
